# 🎬 MARQUEE

### Your Time. Your Movies. Your Verdict.

**MARQUEE** is a modern movie and TV-series discovery platform designed to help users discover trending movies, binge-worthy series, and content available across popular streaming platforms.

🌐 **Live Demo:** https://marquee-1.netlify.app/

---

## 📌 Overview

MARQUEE is a web-based entertainment discovery application that brings movies and TV series together in one interactive interface.

Users can search for movies and series, explore trending content, discover titles based on different categories, check popular content on streaming platforms, and maintain a personal watchlist.

The application uses the **TMDB (The Movie Database) API** to retrieve movie and TV-series information dynamically.

> **MARQUEE — Your Time. Your Movies. Your Verdict.**

## 🔌 API Integration

MARQUEE uses the **TMDB API** to retrieve movie and television information.

The API can provide information such as:

* Movie titles
* TV-series titles
* Posters
* Backdrops
* Ratings
* Release dates
* Genres
* Trending content
* Popular content
* Search results

### Getting a TMDB API Key

1. Create an account on TMDB.
2. Open your account settings.
3. Go to the API section.
4. Generate an API key.
5. Enter the API key when prompted by MARQUEE.

⚠️ **Never upload your private API credentials or secrets directly to a public GitHub repository.**
